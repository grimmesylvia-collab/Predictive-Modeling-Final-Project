# Predictive-Modeling-Final-Project

This repository analyzes student performance data using predictive modeling and statistical analysis techniques to identify patterns and factors influencing academic outcomes, evaluate model accuracy, and support data-driven insights for educational decision-making. The results for this project can be used to determine the most practical and efficient study methods and approaches for student to succeed. 

The Dataset consists of data from 500 students, including study habits and test scores. We were able to evaluate using different models and comparing model accuracy.
